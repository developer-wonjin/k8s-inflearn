# 1) Metrics Server 확인

원문 : https://cafe.naver.com/kubeops/530 (1. Metrics Server 설치)

HPA는 **"지금 CPU를 얼마나 쓰고 있나"** 를 알아야 판단할 수 있다.
그 값을 모아 API로 제공하는 것이 Metrics Server다.

**Metrics Server가 없으면 HPA는 아무것도 못 한다.**
Ingress에 Controller가 필요했던 것과 같은 구조다.

```
kubelet(각 노드) ──▶ Metrics Server ──▶ metrics.k8s.io API ──▶ HPA
                                                            └─▶ kubectl top
```

## 설치 확인

이 클러스터는 구축할 때 함께 설치됐다. **확인만 하면 된다.**

```bash
clear                                          # 화면 정리 후 시작
kubectl get pod -n kube-system | grep metrics  # Pod 이 떠 있는가
kubectl get apiservices | grep -i metrics      # API 가 등록됐는가
```

```
metrics-server-7db4fb59f9-pwlf5   1/1   Running   7 (28h ago)   42d

v1beta1.metrics.k8s.io   kube-system/metrics-server   True   42d
```

`v1beta1.metrics.k8s.io` 의 상태가 **`True`** 여야 한다.
`False` 면 Metrics Server가 죽었거나 인증서 문제가 있는 것이고, HPA도 동작하지 않는다.

## 실제 값 조회

```bash
clear             # 화면 정리 후 시작
kubectl top node  # 노드별 사용량
```

```
NAME          CPU(cores)   CPU%   MEMORY(bytes)   MEMORY%
k8s-master    379m         9%     2924Mi          76%
k8s-worker1   33m          1%     830Mi           29%
k8s-worker2   33m          1%     918Mi           32%
```

```bash
clear                             # 화면 정리 후 시작
kubectl top pod                   # Pod 별 사용량
kubectl top pod -A --sort-by=cpu  # CPU 를 많이 쓰는 순
```

> `kubectl top` 은 **`kubectl get` 과 다른 API를 쓴다.**
> `metrics.k8s.io` 라는 별도 API이고 Metrics Server가 제공한다.
> 그래서 Metrics Server가 죽으면 `kubectl top` 도 함께 안 된다.

## 값이 안 나올 때

Metrics Server는 **약 15초 주기**로 수집한다. Pod을 방금 만들었으면 잠시 기다려야 한다.

```
error: metrics not available yet
```

이 메시지는 고장이 아니라 **아직 수집 전**이라는 뜻이다.

HPA에서도 같은 이유로 초기에 이런 이벤트가 뜬다.

```
Warning  FailedGetResourceMetric  failed to get cpu utilization:
         did not receive metrics for targeted pods (pods might be unready)
```

Pod이 뜬 직후 한두 번 나오고 사라진다면 정상이다.

## 배운 것

- HPA는 **Metrics Server 없이는 동작하지 않는다.**
- `kubectl get apiservices | grep metrics` 의 상태가 `True` 여야 한다.
- `kubectl top node` / `kubectl top pod` 으로 실제 값을 볼 수 있다.
- 수집 주기가 있어 **Pod 생성 직후에는 값이 없다.** 잠깐의 오류 메시지는 정상이다.
